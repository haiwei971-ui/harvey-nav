Verification Philosophy

Three rules that catch 90% of silent AI failures

No bloated frameworks — just deterministic shell checks run before you review a single line.

01 / EXIT CODES

Raw exit codes beat prose summaries

Piping test runners into tail or formatters masks exit code 1 behind exit 0. Enforce set -o pipefail on every agent command so failures stay loud.

02 / ADVERSARIAL INPUTS

Shape matching isn't data validity

A date regex matching 2026-11-22 can still accept 2026-13-45, and Python's json.loads() silently parses NaN. Always test impossible inputs locally.

03 / BLAST RADIUS

Inspect disk state and git diffs

Agents love "fixing" a test by editing assertions under tests/ or skipping files in batch moves. Check git diff --name-only and comm -23 before accepting.
